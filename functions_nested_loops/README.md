# C - Functions, nested loops

This project is part of the ALU Low Level Programming curriculum. It focuses on C functions, nested loops, variable scope, function prototypes, and basic problem solving using the C programming language.

## Learning Objectives

At the end of this project, I should be able to explain:

- What nested loops are and how to use them
- What a function is and how to use functions
- The difference between a declaration and a definition of a function
- What a prototype is and why it is useful
- The scope of variables
- What the GCC flags `-Wall -Werror -Wextra -pedantic -std=gnu89` do
- How to use header files
- How to use loops to solve programming problems
- How to work with integers and ASCII characters
- How to use the modulo operator
- How to write clean C code following Betty style

## Requirements

- Ubuntu 20.04 LTS
- GCC
- C programming language
- Betty style and documentation checks
- All files end with a newline
- No global variables
- Maximum of 5 functions per file
- Code compiled with:

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89
