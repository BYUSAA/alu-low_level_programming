# Recursion

This project introduces recursion in C programming.

## Learning Objectives

At the end of this project, I should be able to:

- Explain what recursion is.
- Implement functions using recursion.
- Understand the base case and recursive case.
- Use recursion to process strings.
- Calculate factorials recursively.
- Calculate powers recursively.
- Find natural square roots recursively.
- Determine whether a number is prime recursively.
- Check whether a string is a palindrome.
- Compare strings using wildcard characters.

## Requirements

- Allowed editors: `vi`, `vim`, `emacs`
- All files are compiled on Ubuntu 20.04 LTS.
- Compilation is done with:
  `gcc -Wall -pedantic -Werror -Wextra -std=gnu89`
- Code must follow the Betty coding style.
- No loops are allowed.
- Recursion must be used where required.
- Static variables are not allowed.
- Standard library functions should not be used unless specifically permitted.
- All function prototypes are declared in `main.h`.

## Files

| File | Description |
|---|---|
| `0-puts_recursion.c` | Prints a string followed by a new line using recursion. |
| `1-print_rev_recursion.c` | Prints a string in reverse using recursion. |
| `2-strlen_recursion.c` | Returns the length of a string using recursion. |
| `3-factorial.c` | Returns the factorial of a given number recursively. |
| `4-pow_recursion.c` | Returns a number raised to a power recursively. |
| `5-sqrt_recursion.c` | Returns the natural square root of a number recursively. |
| `6-is_prime_number.c` | Determines whether an integer is a prime number recursively. |
| `100-is_palindrome.c` | Determines whether a string is a palindrome recursively. |
| `101-wildcmp.c` | Compares two strings where `*` can represent any string. |

## Header File

The project uses `main.h` to contain the function prototypes used by the recursion programs.
