# Custom Analysis — Academic Risk Index (ARI)

## Purpose
ARI is a simple grade-based indicator that highlights students who may need additional academic support.

## Formula
For each student:

`ARI = 100 - grade`

The result ranges from 0 to 100. A higher value indicates greater grade-based risk.

## Categories
- High risk: grade below 50.
- Moderate risk: grade from 50 up to (but not including) 70.
- Good standing: grade from 70 through 100.

## Class average
`Average ARI = sum of individual ARI scores / number of students`

## Example
For a grade of 42, ARI = 100 - 42 = 58. The student is in the high-risk category because the grade is below 50.

## Interpretation and limitations
The report gives category counts and average class ARI. This is a screening indicator only: it does not account for attendance, assessment difficulty, progress over time, or personal circumstances.
